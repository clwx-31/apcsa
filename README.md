# AP Computer Science A

Coursework and daily class notes.

## 📓 Read the notes: **<https://clwx-31.github.io/apcsa/>**

Every class day gets a full write-up — every concept from the lesson
(including the basics), a line-by-line walkthrough of the code we wrote, the
errors we actually hit and how to read them, vocabulary, and practice
questions with answers.

Written so a classmate who missed class can catch up completely.

## This repo

| Path | What it is |
|---|---|
| `*.java` | the programs written in class |
| `docs/` | the Jekyll site published to GitHub Pages |
| `docs/_posts/` | one markdown file per class day |
| `docs/POST-TEMPLATE.md` | the required structure for every entry |
| `docs/README.md` | working agreement: content vs. presentation |

## Running a program

```sh
javac HappyFacePrgrm.java   # compile
java HappyFacePrgrm         # run
```

